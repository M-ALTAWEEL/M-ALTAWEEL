## 🚀 Featured Projects

### 💰 [Budget Analysis](https://github.com/M-ALTAWEEL/budget-analysis)
An AI expense tracker and savings coach for students, in English, Arabic and Turkish.
- **Expense categorizer built from scratch**: Naive Bayes and softmax regression written in NumPy, matching scikit-learn, compared against 8 models with 5-fold cross-validation, and chosen for honest confidence (calibration).
- **In-app assistant** that answers questions like *"How much did I spend on food last month?"* from the user's own data, with no paid AI service (~90% accuracy).
- **End-of-month forecast** that handles one-off payments like rent, cutting early-month error from 52% to 28%.
- Full-stack: Next.js 16 + FastAPI + PostgreSQL, secure auth (rotating refresh tokens, Google sign-in), 140+ backend tests, CI on GitHub Actions, Docker.

### 🌍 [World Happiness Predictor & Analyzer](https://github.com/M-ALTAWEEL/ML-project)
A Streamlit app that merges the World Happiness Report with global health data to predict and explain happiness scores.
- Random Forest regression with an interactive predictor.
- Explainable AI with **SHAP**, exploratory analysis, and **K-Means + PCA** country clustering.

### 🧪 [AI-Augmented Software Engineering](https://github.com/M-ALTAWEEL/AI-Augmented-Software-Engineering)
Weekly work for the AI-Augmented Software Engineering course at İstinye University, including spec-driven development and MCP, with contributions back to the course repository.
